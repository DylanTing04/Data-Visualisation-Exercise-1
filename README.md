## Project Overview
This project is a multi-page web platform created to showcase Australian household appliance energy consumption insights. The site serves as the foundation for hosting upcoming interactive D3.js and KNIME data visualisations.

---

## File Structure
- `index.html` — Landing page / default entry point for the website.
- `televisions.html` — Television energy efficiency insights and placeholder area for future dataset charts.
- `about.html` — Project information and unit background.
- `Style.css` — Custom styling featuring a warm gold and brown palette inspired by the project icon.
- `script.js` — Client-side JavaScript file verifying page loads.
- `PowerIcon.png` — Brand logo asset displayed in the navigation bar.

---

## How to Run
1. Ensure all files (`.html`, `Style.css`, `script.js`, and `PowerIcon.png`) are located in the same root folder.
2. Open `index.html` (or `home.html`) in any modern web browser (e.g., Google Chrome, Microsoft Edge, Firefox).
